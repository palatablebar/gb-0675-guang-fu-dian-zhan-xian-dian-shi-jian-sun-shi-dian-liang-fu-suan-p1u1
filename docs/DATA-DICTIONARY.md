# 功率与限电定义

设备额定功率为kW。遥测kW与MW统一为kW，辐照度为W/m²。样本时刻须带偏移，统一UTC。记录代表自采样时刻起600秒的左值保持区间，超过600秒不外推，缺测保持未定。
每台设备重叠或相邻限电事件先求并集，再按遥测及有效期边界切分半开区间。样例INV-A的10:00–10:20及10:10–10:30合并为30分钟，不能重复积分重叠10分钟。
基线只采用同区域、同采样时刻、同100W/m²辐照档、健康且不处于限电中的参考逆变器；至少2台。对参考功率按各自额定功率归一，取中位数再乘目标额定功率，基线不超过目标额定功率。无合格对照返回NO_REFERENCE及null损失，不填0。
每片段损失=max(基线−实际,0)×秒数/3600。实际高于基线时损失0。计算保留Decimal精度，汇总后统一保留0.0001kWh；未定时长单独展示，不并入已确定损失。
# 响应确认与可结算裁定
调度限电指令只划定指令时段，是否结算以现场遥测证据为准，逐切片裁定四种状态：
- CONFIRMED 可结算：指令时段内（基线−实际）/基线达到响应门槛 response_drop_ratio（默认0.10），且限电并集结束后 recovery_window_seconds（默认600秒，半开区间 (结束, 结束+窗口]，不外推）内存在健康目标样本，其功率与同刻复用基线拟合规则得到的基线偏差不超过 recovery_tolerance（默认0.05）。恢复证据样本号记入 recovery_id。
- PENDING_RESPONSE 待查响应：指令已下达但出力下挫未达门槛（response_code=NO_DROP），现场未响应，损失不得混入正式口径。
- PENDING_RECOVERY 待查恢复：已确认下挫，但恢复窗口内无健康样本、无合格对照或未回到基线容差（RECOVERY_UNPROVEN），恢复滞后或证据不足。
- UNCONFIRMED 未定：缺测、设备故障或无合格对照导致基线/实际缺失（EVIDENCE_GAP），损失保持 null，不填0、不进可结算也不进待查。
可结算损失 settled_loss_kwh 只汇总 CONFIRMED 片段；待查损失 pending_loss_kwh 单列 PENDING_RESPONSE 与 PENDING_RECOVERY。两者之和必须等于全部已确定损失（settlement_balanced），待查与未定均不得混入正式损失。封存需无隔离、无未定且无待查片段。
# 复核重算
POST /api/runs/{run_id}/rerun 基于该批不可变输入快照先完整重算再原子替换：evaluate 失败时尚未写库，旧版结果、revision 与状态原样保留；替换在单事务内按同批号 UPDATE，批号不符即拒绝。任何失败后重试都不新增批次、不造成数据丢失，复核版本号与“已复核”状态不被重算清零。
清批INV-A基线100kW、实际60kW、并集30分钟，损失20kWh；INV-B基线50、实际30、20分钟，损失6.6667kWh。总确定损失26.6667kWh。能量核验按实际+非负损失计算可解释基准电量。
同设备同一时刻不同观测全部隔离；同值重复观测保留稳定编号。封存需无隔离和未定片段。此工具供离线复算，不包含生产控制或电网调度。
